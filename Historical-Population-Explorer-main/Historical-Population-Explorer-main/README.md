*Historical Population Explorer* is a full‐stack web application that lets users visualize and explore population data over time. The frontend (React) displays interactive charts and (eventually) a choropleth map, while the backend (FastAPI) serves cleaned population data and computes a concise summary of overall growth.

# Features

**Interactive Time Series Chart**

  * Displays world‐wide population totals (or filtered by one or more country codes) for the selected year range.
  * Hovering on points shows exact population values.
  * Responsive resizing.

**(Future) Choropleth Map View**

  * Color‐coded countries by population for a single “Map Year.”
  * Pan, zoom, and country popups with population info.

**Population Summary**

  * Automatically computes and displays a one‐line summary:

    > e.g. “Between 1960 and 1965, World population grew from 30,478,264,983 to 33,610,132,728, a 10.3% increase.”

**Year Range & Country Filters**

  * Choose any start/end year between 1960 and 2020.
  * Multi‐select dropdown to filter by ISO‐3 country codes.
  * If no country is selected, the chart uses the global total.

**Cleaned Data Pipeline**

  * `clean_data.py` transforms raw CSV → “long” JSON records (Year, Population, pct\_change, rolling\_average).
  * Only years 1960–2020 are retained.
  * All missing values dropped (with optional interpolation commented out).

# Tech Stack

**Backend**

  * [Python 3.10+](https://www.python.org/)
  * [FastAPI](https://fastapi.tiangolo.com/) (REST API)
  * [Uvicorn](https://www.uvicorn.org/) (ASGI server)
  * [Pandas](https://pandas.pydata.org/) (data cleaning)
  * JSON files for “clean” population data

**Frontend**

  * [Node.js 14+ / npm or yarn](https://nodejs.org/)
  * [React 18+](https://reactjs.org/) (functional components / hooks)
  * [Chart.js 4+](https://www.chartjs.org/) & [react‐chartjs‐2](https://github.com/reactchartjs/react-chartjs-2)
  * [React‐Leaflet](https://react-leaflet.js.org/) & [Leaflet.css](https://leafletjs.com/) (for the eventual choropleth)
  * Plain CSS (no additional UI library, minimal styling in `App.css`)

# Getting Started

## Prerequisites

  **Python (3.10+)**
  **pip** (or `pipx`, `pipenv`, etc.)
  **Node.js (14+)** and **npm** (or **yarn**)

---

## Installation

1. *Clone the repository*

   ```
   git clone https://github.com/yourusername/historical-data-explorer.git
   cd historical-data-explorer
   ```

2. *Set up the backend*

   ```
   cd backend
   python3 -m venv .venv
   source .venv/bin/activate      # on Linux/macOS
   # .venv\Scripts\activate.bat   # on Windows (PowerShell)
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. *Generate / Refresh Clean Data*

   > If you make changes to `clean_data.py` or replace the raw CSV, re-run:

   ```
   python src/clean_data.py
   ```

   This will produce `data/clean/population_clean.json`.

---

## Running the Backend

1. *Activate virtual environment*

   ```
   cd backend
   source .venv/bin/activate     # (or on Windows: .venv\Scripts\activate)
   ```

2. *Start Uvicorn*

   ```
   uvicorn src.main:app --reload
   ```

   * The API will be available at `http://127.0.0.1:8000/`.
   * Visit `http://127.0.0.1:8000/docs` for the automatic OpenAPI/Swagger UI.

---

## Running the Frontend

1. *Open a new terminal* and navigate to the frontend folder:

   ```
   cd ../frontend
   npm install     # or yarn install
   ```

2. *Start React Dev Server*

   ```
   npm start       # or yarn start
   ```

   * By default, the app runs at `http://localhost:3000/`.
   * The React client will fetch data from `http://127.0.0.1:8000/` (CORS is enabled in the backend).

---

# Usage

1. *Navigate to* `http://localhost:3000/` in your browser.
2. *Adjust “Start Year” / “End Year”* to any integers between 1960 and 2020.
3. *Select “View”*:

    **Chart** (default): Shows a time‐series line plot of total population.
    **Map**: (Placeholder or future choropleth) “Map view coming soon…”.
4. *(Optional) Choose one or more countries** from the multi‐select dropdown:

   * If nothing is selected, the chart shows the world total.
   * If one or multiple ISO‐3 codes are selected, it filters to just those country populations.
5. *Summary Box** (below the header) automatically updates:

   > “Between 1960 and 1965, World population grew from 30,478,264,983 to 33,610,132,728, a 10.3% increase.”

   * If exactly one country is selected, the summary shows that ISO code instead of “World.”
   * If multiple countries are selected, it says “X selected countries.”

# API Endpoints

Assuming the backend is running at `http://127.0.0.1:8000/`:

1. *List Topics*

   ```
   GET /topics
   Response: ["population"]
   ```

2. *List Countries*

   ```
   GET /countries
   Response: [
     { "code": "AFG", "name": "Afghanistan" },
     { "code": "ALB", "name": "Albania" },
     …
   ]
   ```

3. *Get Data*

   ```
   GET /data?topic=population&start=1960&end=1965
   GET /data?topic=population&start=1960&end=1965&country=USA&country=IND
   Response: [
     {
       "Country Name": "World",
       "Country Code": "WLD",
       "Year": 1960,
       "Population": 30478264983,
       "Pct_Change": null,
       "Rolling5Y": 30478264983
     },
     { … },
     …
   ]
   ```

4. *Get Summary*

   ```
   GET /summary?topic=population&start=1960&end=1965
   GET /summary?topic=population&start=1960&end=1965&country=USA
   Response: { "summary": "Between 1960 and 1965, World population grew from 30,478,264,983 to 33,610,132,728, a 10.3% increase." }
   ```
